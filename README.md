# Student Management System in C

## 📌 Project Overview
The Student Management System is a simple console-based application developed using the C programming language. It helps users manage student records by allowing them to add, display, and search for student information.

This project is developed as a **First-Year College Programming Project** to understand the basic concepts of C programming.

## ✨ Features

- **Add Student:** Add student details such as roll number, name, and marks.
- **Display Students:** View all stored student records.
- **Search Student:** Search for a student using their roll number.
- **Exit:** Close the application.

## 🛠️ Technologies Used

- Programming Language: C
- Compiler: GCC
- Concepts Used:
  - Structures (`struct`)
  - Arrays
  - Loops (`for`, `do-while`)
  - Conditional Statements (`if-else`)
  - Switch Case
  - Input/Output Functions (`printf`, `scanf`)

## 💻 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/student-management-system.git
```

### Step 2: Open the Project Folder

```bash
cd student-management-system
```

### Step 3: Compile the C Program

```bash
gcc main.c -o student
```

### Step 4: Run the Program

```bash
./student
```
